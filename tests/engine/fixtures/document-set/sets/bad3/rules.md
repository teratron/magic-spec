# Rules

## R1 — Format code

Run the formatter before committing.

- Applies to: all
- From: M1
- Checked by: the formatter in `ci`
- Why: one style everywhere

## R2 — Extras are listed

Every extra greeting is listed.

- Applies to: hello
- From: M1
- Checked by: the list check of `extra`
- Why: users find them

## R3 — Greetings are checked

Every greeting is checked for spelling.

- Applies to: hello
- From: M2
- Checked by: the spelling job of `ci` over `hello`
- Why: users read them
