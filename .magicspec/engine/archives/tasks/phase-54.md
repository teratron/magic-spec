# Stage 54 Tasks — Artifact Memory Index

**Phase:** 54
**Status:** Done
**Strategic Goal:** A local index over the state folder's artifacts, one row per section with its provenance, answers a content question with ranked citations — lexical always, semantic only when the person configures a provider — and never answers from a stale section. `memory-index` builds it, `memory-query` reads it, `export-wiki` refreshes it with the graph, and the three comparison-set searches of the review gates use it first. It is rebuilt from the artifacts at any time, sends nothing anywhere unless configured, and a failure to build or query it never fails a workflow. No package is added to the shipped engine.

- **Fixture root (plan note 2).** Every harness case that calls a writing subcommand in process passes the fixture root. Without it the call finds the real project from the working directory and writes `.magicspec/.cache/memory.*` there.
