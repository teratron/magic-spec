# Stage 50 Tasks — Review Gates: Coherence Check and Input Prompt Pass

**Phase:** 50
**Status:** Done
**Strategic Goal:** Before a specification or a plan is finalized it is compared with every artifact that shares a mechanic with it — not only the ones it declares — and a contradiction, a duplicate definition, an interaction gap or an ordering conflict is resolved before it is written; and every piece of human prose that arrives with a command passes through the `prompt-engineer` first, so the workflow acts on a precise intent statement that keeps every clause, separates pasted material from the request and stays silent when it agrees with the literal reading.
